# London Bike Ride Data Analysis Dashboard

The London Bike Ride Data Analysis project is an end-to-end data analytics and visualization project that analyzes bike-sharing trends in London using historical ride and weather data. The project focuses on understanding how environmental factors such as weather conditions, temperature, humidity, wind speed, seasons, weekends, and holidays influence bike rental demand.

The project combines Python for data cleaning and transformation with Tableau for interactive dashboard development, enabling users to explore patterns and gain actionable insights from the dataset.

## 🎯 Project Objectives

* Analyze bike-sharing demand in London.
* Understand the impact of weather conditions on bike rentals.
* Explore seasonal and daily usage patterns.
* Identify factors influencing rider behavior.
* Create an interactive dashboard for business insights.
* Demonstrate the complete data analytics workflow from data cleaning to visualization.
